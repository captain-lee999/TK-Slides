### [표지] : 솔루션 영업에서 통찰력 판매로 (부제 : HBR 「The End of Solution Sales」 재구성 · '26.11)

### [목차]
- 스토리 라인: 고객이 구매 결정의 약 60%를 영업사원 없이 끝내므로, 요구에 답하는 솔루션 영업을 버리고 고객의 생각을 바꾸는 통찰력 판매로 고객 선별·이해관계자·구매 지도 방식을 바꿔야 한다
- Ⅰ. 영업 환경 변화 : 1. 통찰력 판매 전환 종합 / 2. 솔루션 영업의 위기 / 3. 솔루션 판매 대 통찰력 판매
- Ⅱ. 통찰력 판매 3대 전략 : 4. 민첩한 조직 선별 / 5. 동원자 공략 / 6. 구매 방법 교육 / 7. 영업 조직 실행 과제

### 본문 1 : Ⅰ- 1. 통찰력 판매 전환 종합
- 물음: 고객 주도 구매 환경에서 영업 조직은 무엇으로 바꿔야 하는가
- 연결: 시작 — 덱 전체 결론과 3대 전략 기둥 제시
- 비중: 핵심
- 리드: ✓ 구매 결정의 약 60%가 영업사원 없이 끝나 3대 통찰력 판매 전략으로 전환이 시급
- 서브메시지:
  - 근거: CEB 3개 연구, B2B 고객 기업 1,400개·영업사원 6,000명 이상 조사('12년)
  - 실행: ☞ 영업본부, '27년 상반기까지 영업사원 평가·육성 체계를 3대 전략 기준으로 재설계
- 주 도식: 전략 하우스 | 지붕: 요구에 답하는 영업에서 생각을 바꾸는 통찰력 판매로 | 바닥: 영업사원 훈련·지원 방식의 근본 재고
- 근거 도식: 수치 타일 | 값: 약 60% 대화 전 끝난 구매 결정 / 1,400개 조사 대상 B2B 고객 기업 / 상위 20% 할당 성취 기준 스타 영업사원
- 본문:
  - 민첩한 조직 선별
    - 대상: 명확한 요구 고객 대신 변화 중인 조직
    - 기준: 구매 잠재력보다 변화 잠재력
    - ✓ 조기 개입: 요구 정의 전에 통찰 제시
    - 결론: 고객 선별 기준부터 바꿈
  - 동원자 공략
    - 대상: 우호적 정보원 대신 회의적 변화촉진자
    - 유형: 수완가·교사·회의론자 3유형
    - ✓ 합의 도출: 조직 안 실제 행동 견인
    - 결론: 만날 사람을 바꿈
  - 구매 방법 교육
    - 방식: 구매 프로세스를 묻지 않고 가르침
    - 도구: 단계별 권고 행동·검증 지표
    - ✓ 이탈 방지: 부서 간 반대 사전 예측
    - 결론: 대화의 주도권을 가져옴
- 사실 띠: CEB 연구 근거 | 연구 1: 83개 기업 영업사원 6,000명 이상 / 연구 2: 약 600개 기업 구매 시나리오 / 연구 3: 고객 이해관계자 700명 이상 / 스타 기준: 할당 성취 상위 20%
- 강조: 약 60%
- 받침: 스타 영업사원은 더 잘 파는 것이 아니라 전혀 다른 방식으로 팖 → 기존 솔루션 영업은 왜 효용을 잃었는가
- 출처: ※ HBR 「The End of Solution Sales」('12.7~8월호, DBR 번역) 재구성

### 본문 2 : Ⅰ- 2. 솔루션 영업의 위기
- 물음: 기존 솔루션 영업은 왜 효용을 잃었는가
- 연결: 인과 — 앞 장의 「약 60%」가 생긴 원인을 고객 구매 방식 변화에서 찾음
- 비중: 보통
- 리드: ✓ 고객이 요건·가격을 먼저 정해 영업사원이 가격 협상에 갇히는 구조가 관건
- 서브메시지:
  - 근거: IT·보험·비즈니스 프로세스 아웃소싱 업계 고객 사례
  - 실행: ☞ 영업전략팀, 제안 요청서 대응 위주 영업 절차 개편 검토('27년 1분기)
- 주 도식: 인과 사슬
- 근거 도식: 수치 타일 | 값: 약 60% 공급업체 대화 전 끝난 구매 결정 / 1980년대 요구 확인 영업의 시작 시점
- 본문:
  - 조달 역량 향상
    - ↑ 조달팀: 구매 수준 향상, 협상 주도
    - ↑ 구매 컨설턴트: 방대한 가격 데이터 보유
    - 자체 탐색: 솔루션을 고객이 스스로 비교
    - 결론: 고객이 공급업체보다 먼저 앎
  - 구매 결정 선행
    - 사전 완료: 조사·순위·요건·가격 벤치마킹
    - 약 60% 대화 전 끝난 구매 결정
    - ! 제안 요청서: 확정 요건으로 공급업체 압박
    - 결론: 영업사원은 결정 뒤에 등장
  - 영업 역할 축소
    - ↓ 영업 대화: 상당 부분이 주문 처리로
    - ↓ 가격 위주: 영업사원 업무를 떠안는 사례 증가
    - ✗ 요구 확인 영업: '80년대식 전술 무력화
    - 결론: 차별화 대신 가격 경쟁만 남음
- 사실 띠: 없음
- 강조: 가격 협상
- 받침: 하이테크 CSO(최고전략책임자), 고객이 솔루션 영업사원을 골칫거리로 여김 → 기존 방식과 새 방식은 무엇이 다른가
- 출처: ※ HBR 「The End of Solution Sales」('12.7~8월호, DBR 번역) 재구성

### 본문 3 : Ⅰ- 3. 솔루션 판매 대 통찰력 판매
- 물음: 기존 방식과 새 방식은 무엇이 다른가
- 연결: 전환 — 앞 장 위기에 대한 반대쪽 방식을 차원별로 맞세움
- 비중: 핵심
- 리드: ✓ 고객 요구에 맞추던 방식을 요구 자체를 다시 정의하는 방식으로 바꾸는 것이 관건
- 서브메시지:
  - 근거: 연구진, 스타 영업사원 약 100명 인터뷰 기반 비교
  - 실행: ☞ 영업기획팀, 기회 검토 회의에 「고객 요구 재정의 여부」 점검 항목 추가('27년 1월)
- 주 도식: 전환표 | 차원: 목표 고객 / 초기 정보 / 개입 시점 / 대화 시작 / 구매 과정
- 근거 도식: 사례 이행
- 본문:
  - 솔루션 영업
    - 명확한 비전·기성 수요를 가진 조직
    - 고객이 풀려는 요구를 수집
    - 문제를 고객이 인지한 뒤 개입
    - 고객 요구를 묻고 솔루션을 연결
    - 고객 구매 과정을 따라감
  - 통찰력 판매
    - 변화 중인 민첩한 조직
    - 고객이 자각 못한 요구를 발굴
    - 문제를 깨닫기 전에 조기 개입
    - 고객이 할 일에 도발적 통찰 제시
    - 구매 방법을 가르치고 이끎
  - [근거] 서비스 기업 A
    - 제안 요청서 답변 발표 준비
    - 빠진 3가지 이슈 60분 제시 → 요청 과정 취소 후 수주
  - [근거] 산업 자동화 B사
    - 평균 영업사원, 구매 잠재력으로 기회 평가
    - 득점표 도입 → 새 수요 쪽 대화 유도
- 사실 띠: 없음
- 강조: 통찰력 판매
- 받침: 전통 방식의 핵심은 지지자·코치를 찾는 능력이었음 → 어떤 고객을 먼저 골라야 하는가
- 출처: ※ HBR 「The End of Solution Sales」('12.7~8월호, DBR 번역) 재구성

### 본문 4 : Ⅱ- 1. 민첩한 조직 선별
- 물음: 어떤 고객을 먼저 골라야 하는가
- 연결: 심화 — 앞 장 「목표 고객」 차원을 선별 기준으로 깊게 봄
- 비중: 보통
- 리드: ✓ 구매 잠재력보다 변화 잠재력이 큰 민첩한 고객을 먼저 공략하는 것이 우선
- 서브메시지:
  - 근거: 스타 영업사원 약 100명 인터뷰로 만든 기회 평가 득점표 기준
  - 실행: ☞ 영업팀, 잠재 고객 평가표에 민첩성·변화 압력 항목 추가('27년 2월)
- 주 도식: 평가표 | 기준: 변화 필요성 인지 / 명확한 목표 / 정립된 구매 절차 / 민첩성 / 변화 압력
- 근거 도식: 이슈 트리 | 뿌리: 변화 압력의 원천
- 본문:
  - 평균 영업사원
    - 변화 필요성 인지: 상 — 핵심 기준
    - 명확한 목표: 상 — 핵심 기준
    - 정립된 구매 절차: 상 — 핵심 기준
    - 민첩성: 하 — 평가 안 함
    - 변화 압력: 하 — 평가 안 함
  - 스타 영업사원
    - 변화 필요성 인지: 하 — 덜 중시
    - 명확한 목표: 하 — 덜 중시
    - 정립된 구매 절차: 하 — 덜 중시
    - 민첩성: 상 — 논거에 신속·결단
    - 변화 압력: 상 — 내외부 압력 직면
  - [근거] 외적 압력
    - 규제 개혁
    - 시장 변화
  - [근거] 내적 압력
    - 인수 합병
    - 경영진 교체
    - 업무 방식 불만
- 사실 띠: 득점표 운영 | 개발: 스타 약 100명 인터뷰 / 적용: 산업 자동화 기업 B사 / 원칙: 체크리스트 아닌 대화 촉매 / 효과: 관료화 방지
- 강조: 변화 잠재력
- 받침: 기성 수요 고객은 이미 요건을 정해 경쟁 입찰로 감 → 고객 조직 안에서 누구를 공략해야 하는가
- 출처: ※ HBR 「The End of Solution Sales」('12.7~8월호, DBR 번역) 재구성

### 본문 5 : Ⅱ- 2. 동원자 공략
- 물음: 고객 조직 안에서 누구를 공략해야 하는가
- 연결: 심화 — 고른 고객 안에서 합의를 이끌 사람을 찾음
- 비중: 핵심
- 리드: ✓ 7유형 중 합의를 이끄는 동원자 3유형을 표적으로 삼는 것이 우선
- 서브메시지:
  - 근거: 고객 이해관계자 700명 이상, 135개 자질·관점 자기 평가
  - 실행: ☞ 영업팀, 거래별 이해관계자 지도에 동원자·수다쟁이 구분 표시('27년 1분기)
- 주 도식: 평가표 | 기준: 조직 개선 지향 / 합의 도출 / 접근 용이성
- 근거 도식: 단계 흐름 | 통찰 반응 평가 → 논의 방식 경청 → 행동으로 시험
- 본문:
  - 동원자
    - 조직 개선 지향: 상 — 생산적 변화 최우선
    - 합의 도출: 상 — 수완가·교사·회의론자
    - 접근 용이성: 하 — 대화가 까다로움
  - 수다쟁이
    - 조직 개선 지향: 하 — 정보 공유 위주
    - 합의 도출: 하 — 안내자·친구·출세주의자
    - 접근 용이성: 상 — 품위 있고 접근 쉬움
  - 방해자
    - 조직 개선 지향: 하 — 현 상태 유지 선호
    - 합의 도출: 하 — 외부 대화에 무관심
    - 접근 용이성: 하 — 대화 자체를 피함
  - [근거] 통찰 반응 평가
    - ✓ 까다로운 질문: 건강한 회의론, 동원자 신호
    - ✗ 질문 없는 수용: 수다쟁이·방해자 신호
    - 결론: 질문이 많을수록 좋은 신호
  - [근거] 논의 방식 경청
    - ! 「우리」보다 「나」: 출세주의자 신호
    - 개인 의제화: 아이디어를 자기 홍보 수단으로
    - 결론: 말투로 동기를 가림
  - [근거] 행동으로 시험
    - 의사결정권자 회의 주선 요청
    - 글로벌 통신기업 C: 후속 회의 초청 요구
    - 결론: 인맥·영향력은 행동으로 확인
- 사실 띠: 동원자의 질문 | 수완가: 실행하고 싶어서 / 교사: 공유하고 싶어서 / 회의론자: 시험하려고 / 그레인저: MRO 비용 40% 비계획 데이터로 반응 확인
- 강조: 동원자 3유형
- 받침: 이상적 지지자 자질 10가지를 모두 갖춘 사람은 존재하지 않음 → 동원자와 함께 구매를 어떻게 끝까지 이끄는가
- 출처: ※ HBR 「The End of Solution Sales」('12.7~8월호, DBR 번역) 재구성

### 본문 6 : Ⅱ- 3. 구매 방법 교육
- 물음: 동원자와 함께 구매를 어떻게 끝까지 이끄는가
- 연결: 대응 — 동원자가 사내 구매 절차에 어둡다는 약점을 공급업체가 메움
- 비중: 보통
- 리드: ✓ 공급업체가 단계별 권고 행동으로 고객의 구매 과정을 이끄는 것이 필요
- 서브메시지:
  - 근거: ADP(오토매틱데이터프로세싱) 「손쉬운 구매」 프로그램 사례
  - 실행: ☞ 영업기획팀, 고객 구매 단계별 권고 행동·검증 항목표 작성('27년 상반기)
- 주 도식: 수영 레인 | 단계: 요구 인지 / 선택 방안 평가 / 솔루션 승인 및 선택
- 근거 도식: 전환표 | 차원: 단계의 의미 / 영업 대화 / 진척 확인
- 본문:
  - 고객 구매 활동
    - 위험 노출 수준 확인
    - 아웃소싱 대안 비교
    - *부서 합의 후 승인
  - ADP 권고 행동
    - 사전 진단 프로그램 제안
    - 자사 도구·문서로 평가 지원
    - 반대·부서 정치 미리 대응
  - 검증 지표
