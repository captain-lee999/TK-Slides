## 1. 프로젝트 배경 및 v5.4 → v6.4 진화 계보

사용자는 v5.4까지 Claude 환경에서 TK-Slides 변환기(`make.html`) 및 기획 스킬(`ppt-slide-planner`)을 개발해왔으나, 이후 다음과 같은 핵심 요구사항이 제기되었습니다:

1. **전사PPT양식 원본 디자인 이탈 문제 (v6.0~v6.1)**:
   - 캔버스 비율 및 브랜드 자산(좌측 세로 나무 일러스트, 우상단 슬로건 `Global Agility & Growth`, 하단 농심태경 및 3대 브랜드 로고, 상단 진녹 `#003300` 헤더 선 + 우상단 베지가든 `Vg` 엠블럼, 청색 `#0058B8` 리드메시지, 하단 실증 띠 등)이 훼손되거나 변경되어 있던 문제를 구글 드라이브 내 공식 마스터 템플릿(`전사PPT양식(템플릿함수)의 사본` / `29.7cm × 21cm` A4 와이드)에서 추출하여 100% 원본 복원했습니다.
2. **장표 내 요소 겹침(Overflow & Collision) 문제 (v6.2~v6.3)**:
   - 워터폴 브리지 상단 수치 라벨 잘림, 수치 타일 2단 분리 시 텍스트 절단, 레이더·버블 맵 라벨 간섭, 토네이도 차트 축 침범, 주 도식과 근거 도식의 중첩 오류를 CSS 그리드 및 적응형 레이아웃(`stack-split`, `side-split`, `side-equal`)으로 전수 해결했습니다.
3. **SlideForge 파이프라인 목차 및 정수 번호 체계 (v6.4 핵심)**:
   - 구글 드라이브의 사내 표준 프레젠테이션 생성 파이프라인인 **SlideForge**(`14_CODE5_DSLInterpreter.gs`, `04_SD-C_시각규격.md`)의 목차 렌더링 방식(`renderToc`)을 완벽히 이식했습니다.
   - **사용자 승인 하드룰 (로마자 전면 금지 & 정수 이원화)**:
     - 목차 및 본문 대제목에 로마자(`Ⅰ·Ⅱ·Ⅲ`, `I·II·III`) 절대 사용 금지.
     - **본문 7장 이내 (1~7장)**: 단일 정수 `1. 제목`, `2. 제목`... (SlideForge `normalizeKicker` 원본 표준).
     - **본문 8장 이상 (8장~)**: 장-절 정수 `1-1. 제목`, `1-2. 제목`, `2-1. 제목`...
4. **슬라이드별 `'다른 안 ↻'` 순환 버튼 및 포커스 고정 복원 (v6.4 핵심)**:
   - v5.4 이전에 제공되던 슬라이드별 대안 도식 순환 버튼을 복원하고, **도식·구도 직접 선택 드롭다운**을 추가하여 35종 컨설팅 도식으로 즉시 점프 가능하도록 구현했습니다.
   - 버튼 클릭 시 `scrollIntoView({ behavior: 'smooth', block: 'center' })`를 호출하여 **해당 슬라이드가 화면 중앙에 그대로 유지**됩니다.
5. **만성적 과도한 여백 및 저밀도 해소 (v6.4 핵심)**:
   - `예비:` 및 `사실 띠:` 항목을 100% 자동 흡수(1차: 카드 내부 최대 4줄, 2차: 하단 핵심 실증 띠)하고, 컨테이너 비례 신축 및 가용 공간에 맞춘 타이포·행간 미세 조정을 통해 **충전율 하한 92%+ (실측 95%~97%)**를 강제했습니다.

## 2. 핵심 아키텍처 및 구현 세부 사항

### 2-1. 목차(TOC) 파이프라인 아키텍처 (`14_CODE5_DSLInterpreter.gs` 포트)

* **스토리 라인 (Storyline)**:
  - 원고의 `[목차]`에서 `- 스토리 라인: <한 문장>`을 읽어 상단 띠 배너(`13.5pt Bold`, 진녹 좌측 바 `#1E5A32`)에 표시합니다.
* **동적 열 분할 (Column Splitting)**:
  - 본문 **1~7장**: **1열(1 Column)** 레이아웃. 행높이 최대 `72pt`까지 확보하여 하단 여백을 없앱니다.
  - 본문 **8~14장**: **2열(2 Columns)** 레이아웃. 중앙에 `1px` 세로 구분선(`DDE3DC`)을 긋고 좌우로 균등 분할합니다.
  - 본문 **15장 이상**: **3열(3 Columns)** 레이아웃으로 자동 확장됩니다.
* **항목별 행 구성 (Row Structure)**:
  - **정수 번호 (`sf-toc-num`)**: 단일 강조색(`3D7A5F`)으로 통일. 9개 이하는 `1`~`9`(`30pt Bold`), 10개 이상은 정렬을 위해 `01`~`NN`(`26pt Bold`) 두 자리로 표기합니다.
  - **슬라이드 제목 (`sf-toc-item-title`)**: 7장 이내는 `물류센터 자동화 1차 성과`, 8장 이상은 `1-1. 갭 분석과 득실 저울 도식`처럼 자동 정규화된 제목을 표기합니다.
  - **하위 키워드 (`sf-toc-item-keys`)**: SlideForge의 `extractTocKeyList_` 로직을 포팅하여, 본문 슬라이드의 셀 이름(`mainCells`), 도식 차원/기준 파라미터, 사실 띠에서 **핵심 키워드 3~4개를 가운뎃점(`·`)으로 자동 추출**하여 제목 아래에 병기합니다.
  - **쪽수 (`sf-toc-page`)**: 표지(1)·목차(2) 다음인 `3`쪽부터 우측 정렬로 표시됩니다.
  - **인터랙션**: 목차 행을 클릭하면 해당 본문 슬라이드로 부드럽게 스크롤 이동합니다.

### 2-2. 슬라이드별 `'다른 안 ↻'` 및 구도 전환 아키텍처

* **상태 관리 (`slideAltState`)**:
  - `slideAltState[sIdx] = { altIdx: 0, directKey: '' }` 객체로 슬라이드별 변형 상태를 격리 관리합니다.
  - 상단 툴바의 `프리셋 1·2 선택`(원고 텍스트 변경)과 슬라이드별 `다른 안`(렌더링 구도 변경)이 충돌 없이 분리 병행됩니다.
* **대안 후보군 자동 생성 (`getSlideAlternatives`)**:
  - 슬라이드의 주 도식 유형에 따라 논리적으로 유효한 6종의 고밀도 대안(예: 전환표 → 갭 분석 ↔ 득실 저울 ↔ 좌우 분할 ↔ 2×2 ↔ 전략 하우스)을 추천합니다.
* **직접 선택 드롭다운 (`DIRECT_DIAGRAM_OPTIONS`)**:
  - 빠른 순환(`다른 안 ↻`) 외에도 사용자가 상하 분할, 좌우 분할, 좌우 반전, 1:1 대칭 및 35종 전체 도식(워터폴, 메리메코, 토네이도, 레이더, 수영 레인, 3×3, 피시본 등)을 직접 고를 수 있는 드롭다운을 제공합니다.
* **포커스 유지 (`scrollToSlide`)**:
  - `cycleSlideAlt(sIdx)` 또는 `selectSlideDirectAlt(sIdx, val)` 실행 후 `requestAnimationFrame`을 통해 해당 슬라이드로 즉시 `scrollIntoView({ behavior: 'smooth', block: 'center' })`를 실행하고 펄스 하이라이트 효과(`alt-active-pulse`)를 부여합니다.
* **PPTX 연동 (`exportDeckToPPTX`)**:
  - 각 슬라이드에서 변경한 `'다른 안'` 구도(상하 분할 vs 좌우 분할 등)가 PptxGenJS 내보내기 시에도 100% 반영됩니다.

### 2-3. 고밀도 충전율 하한(92%+) 강제 엔진

* **2단계 예비 흡수 파이프라인**:
  - **1단계 (Cell Absorption)**: 원고 내 `예비:` 항목 중 본문 칸 이름과 어근이 일치하는 항목을 해당 칸 안으로 흡수(칸당 최대 4줄까지, 슬라이드 전체 21줄 이하 안전선 유지).
  - **2단계 (Fact Band Absorption)**: 1단계에서 흡수되지 않고 남은 예비 항목들을 슬라이드 하단의 `핵심 실증·보조 근거 띠`로 자동 변환하여 슬라이드 하단이 비는 현상을 원천 방지합니다.
* **적응형 타이포그래피 (Adaptive Typography)**:
  - 본문 줄 수에 따라 CSS 변수 `--sl-font-body`(`10.8px~12.2px`), `--sl-line-pitch`(`1.35~1.50`), `--sl-card-pad`가 동적으로 조정되어 과밀도(겹침)와 저밀도(빈 공간)를 동시에 차단합니다.
* **10대 무결성 실시간 감사 엔진 (`auditDeck`)**:
  - 10개 핵심 규격(기호 정합성, 정수 표기, 슬래시 오염 차단, 리드 40자 종결, 수치 타일 규격, 고정 줄 수 일치, 주/근거 칸 분리, 60-30-10 포컬 강조, 충전율 92%+ & 24줄 상한, 마지막 장 실행 표)을 100점 만점으로 계측합니다.
