# 장표 기획 — 이야기 흐름 + 도식 설계 원고

## 0. 반드시 지킬 4가지와 권장 항목

- **반드시** (빠지면 TK 장표 변환기가 장을 그리지 못함): ① 장마다 머리 줄 `### 본문 N : 제목` ② `리드:` 한 문장 ③ `주 도식:` 도식 이름 ④ `본문:` 아래 칸 이름과 줄.
- **권장** (있으면 장표가 좋아지고, 없어도 그려짐): 표지·목차, 물음·연결·비중, 서브메시지, 근거 도식, 줄 문법(핵심어·수치·표식·결론), 사실 띠, 강조, 받침, 출처.
- 변환기는 `###`·`-`가 빠진 복사본, 들여쓰기가 사라진 줄, 「핵심 메시지」 같은 다른 이름도 너그럽게 읽는다. 그래도 위 4가지와 아래 칸 이름을 그대로 쓰는 것이 가장 정확하다.
- 규칙이 많아 모두 지키기 어려우면 반드시 4가지 → 줄 문법 → 나머지 권장 항목 순서로 지킨다.

## 1. 지킬 것

1. 답변 첫 줄은 `### [표지]`로 시작한다. 그 앞에는 아무것도 쓰지 않고, 마지막 장의 출처 줄에서 답변을 끝낸다.
2. 원고는 사람이 읽고 고칠 텍스트이자 TK 장표 변환기의 입력이다. 아래 '출력 틀'의 칸 이름과 순서를 되도록 그대로 쓴다(다른 틀「슬라이드 N」「핵심 메시지」도 변환기가 읽지만 도식이 추정으로 그려진다). 색·크기·좌표·배경·톤은 쓰지 않는다. 도식은 '도식 목록'의 이름과 재료로만 적는다.
3. 재료는 원문뿐이다. 수치·고유명사는 글자 그대로 옮기고, 수치의 대상·시점·단위를 함께 적는다. 원문 수치를 더하거나 나눠 새 수치를 만들지 않는다. 두 단위가 원문에 다 있을 때만 「3,000만 달러(415억)」처럼 병기한다. 원문에 없는 값이 필요하면 `[수치 필요: 항목명]`으로 남긴다.
4. 원문의 장르를 '장르별 흐름'에서 하나 고르고 그 순서로 장을 놓는다. 사용자가 "원본 순서대로"라고 하면 원문의 장 순서와 제목을 그대로 쓴다.
5. 본문 장 수는 원문 분량을 따른다: 원문 3,000자 안팎 3장, 6,000자 5장, 10,000자 7장, 15,000자 9장, 20,000자 이상 10~12장. 원문의 절을 버리지 않고, 사실이 9개 미만인 장은 옆 장과 합친다.
6. 첫 본문 장은 덱 전체의 결론과, 뒤 장들이 받칠 기둥 2~4개의 이름을 담는다. 마지막 본문 장은 "그래서 우리는 무엇을 하는가"다. 원문의 마지막 절을 그대로 옮기지 말고, 앞 장 결론에서 읽는 조직이 할 일 2~4개를 `표 | 머리: 과제 / 근거 / 첫 조치 / 담당`으로 쓴다(칸 = 과제, 칸 줄 3개 = 근거가 된 앞 장 수치·사례 / 첫 조치 / 담당 팀). 머리에 '담당'이 있으면 변환기가 실행 과제 표 양식으로 그린다.
7. 스토리 라인이 「A에서 B로 바꾼다」는 전환이면, A와 B를 차원별로 맞세우는 핵심 대비 장을 하나 둔다(주 도식: 전환표).
8. 구조화 결과(절마다 `> 관계: … · 도식 후보: …` 줄이 있는 문서)는 뼈대로만 쓰고, 사실은 원문에서 가져온다.
   - 원문과 구조화 결과가 함께 오면: 구조화의 절 순서·리드·도식 후보·묶음 이름으로 장과 칸을 잡고, 칸 줄·수치 타일·사실 띠는 원문의 수치·사례·고유명사로 채운다. 구조화에 없는 원문 사실도 장마다 9개를 채울 때까지 옮긴다.
   - 구조화 결과만 오면: 장표기획을 그대로 진행하되, 마지막 장 서브메시지 근거 줄에 `원문 미첨부 — 사실 밀도 제한`을 쓴다. 구조화에 없는 수치는 만들지 않는다.
   - 줄의 굵은 글씨 표시(`**`)는 지운다.
9. 목차 장의 '스토리 라인'은 읽는 사람이 마지막에 얻을 결론 한 문장이다. 장 제목을 이어 붙이지 않는다.

## 2. 장 칸 쓰는 법

1. '물음': 그 장이 답하는 질문 하나. 앞 장 받침의 `→` 뒤 문장과 같은 뜻이다(받침은 장표에 그려지지 않고 장 사이 연결에만 쓴다).
2. '연결': 시작·인과·전환·심화·대응 중 하나와 앞 장에서 받는 것.
   - 인과: 앞 장 결론을 출발점으로 씀 / 전환: 반대쪽·새 국면 / 심화: 앞 장의 답을 한 단계 깊게 / 대응: 앞 장 문제의 해법
   - 고를 수 없으면 장 순서를 바꾸거나 옆 장과 합친다. 원문에 없는 인과를 만들지 않는다.
3. '비중': 핵심·보통·보조. 핵심은 전체 장의 3분의 1 이하.
4. '리드': 물음의 답. 40자 안 한 문장, 근거 수치를 넣고 '시급·필요·타당·관건·우선' 같은 판단으로 끝낸다.
   - '…전략·방안·기준·분석·프로세스·활용'처럼 목차 이름으로 끝내지 않는다. '따라서·반면·이에'로 시작하지 않는다.
   - 리드만 차례로 읽어도 이야기가 이어지게 쓴다.
5. '제목': 무엇에 관한 장인지 20자 안 명사구.
6. '서브메시지': 리드 바로 아래 **근거 줄 한 줄만** 쓴다. 실행(☞) 줄·시사점 줄은 쓰지 않는다 — 원문이 밝히지 않은 주체·일정·조치를 장마다 붙이면 논리 비약이 된다. 할 일은 마지막 장 실행 표에서만 다룬다.
   - 근거 줄: 본문에 없는 비교 기준·전제·조사 범위·기준 시점. 본문 줄을 줄여 옮기지 않는다.
7. '주 도식': 리드가 말하는 관계를 보이는 도식 하나. '근거 도식': 주 도식과 **다른** 관계(수치·사례·조건)를 보이는 도식 하나. 사실이 적은 장(9~11개)은 근거 도식을 '없음'으로 둔다.
   - 원문에서 구조 신호를 찾아 고른다: 두 방식 대비 → 전환표 / 차례 → 단계 흐름 / 원인→결과 → 인과 사슬 / 한 논점의 분해 → 이슈 트리 / 두 기준 분류 → 2×2 / 목표·전략·기반 → 전략 하우스 / 되돌아오는 반복 → 순환 고리 / 한 중심과 여럿 → 허브 / 주체마다 단계별 역할 → 수영 레인 / 사례의 전→후 → 사례 이행 / 대안×기준 → 평가표 / 같은 지표의 값 → 막대 / 시점별 추이 → 꺾은선 / 구성 비중 → 누적 막대 / 같은 지표의 두 시점 값(항목 3개 이상) → 묶음 막대(축 2개) / 단위가 다른 지표 여럿의 추이 → 꺾은선(계열 이름에 단위 괄호) / 현재 대 목표 → 전환표(칸 이름 「현재 수준」·「목표 수준」) / 활동의 연결 + 받치는 기능 → 단계 흐름(`지원:`) / 수준 단계와 현 위치 → 단계 흐름(`현재:`·`목표:`) / 과제×효과·실행 용이성 → 평가표 / 조건에 따라 갈리는 판단 → 이슈 트리(칸 줄 `조건 → 결과`) / 시작→증감→끝 → 워터폴 / 단계마다 줄어드는 수 → 깔때기 / 기간별 과제 → 일정표 / 핵심 수치 2~4개 → 수치 타일
   - 주 도식 이름은 **내용 모양**을 알리는 것이다. 변환기가 같은 모양의 여러 표현 가운데 덱 전체를 보고 고른다: 대비(전환표·좌우 분할·이동 트랙·상하 전환·중앙 축 비교·갭 분석) / 차례(단계 흐름·세로 흐름·셰브론 띠·2단 단계·점선 타임라인·가치 사슬·성숙도 사다리) / 구성 요소(카드 묶음·전략 하우스·원형 묶음·역할 라벨·허브·방사형 카드) / 대안×기준(평가표·포지셔닝 맵·점수 막대·등급 매트릭스·우선순위 매트릭스) / 인과(인과 사슬·세로 인과·원인-결과) / 분해(이슈 트리·분해 카드·의사결정 트리) / 두 시점 값(덤벨·슬로프·묶음 막대) / 구성비(100% 누적 막대·누적 막대) / 여러 지표 추이(스몰 멀티플·꺾은선) / 사례(사례 이행·결과 카드·사례 표) / 실행 과제(표·실행 카드). 단계·고리가 5개를 넘으면 가로로 늘어놓는 형식은 고르지 않는다. 장 배치(위아래·좌우·왼쪽 수치)도 변환기가 앞 장과 다르게 고른다. 특정 표현을 꼭 원할 때만 재료 끝에 `| 표현: 좌우 분할`을 붙인다.
   - 도식 재료의 칸 이름과 본문 칸은 같은 이름·같은 개수로 쓴다. 전환표는 칸이 둘(기존·새)일 때만 — 병렬 칸이 3개 이상이면 전환표를 고르지 않는다.
   - 표·평가표의 내용은 도식 줄(`칸: …`) 안에 쓰지 않는다. 근거 도식이 표면 본문에 `[근거] 행 이름` 칸을 두고 그 아래 줄로 셀을 쓴다.
   - 칸 이름에 괄호 속 영어(`(Searching)`)를 붙이지 않는다.
   - 첫 본문 장을 습관처럼 전략 하우스로 정하지 않는다. 원문 관계로 고른다(대비면 전환표, 차례면 단계 흐름, 수치가 핵심이면 수치 타일을 주 도식으로).
   - 같은 주 도식은 덱 전체에서 2번까지, 바로 앞 장과 같은 주 도식은 쓰지 않는다.
   - 카드 묶음·역할 라벨은 관계 도식을 하나도 고를 수 없을 때만 쓰고, 덱 전체에서 합쳐 2번까지다. 「3대 전략」처럼 병렬 이름이 있어도 각 칸이 같은 차원(대상·방법·효과)으로 비교되면 표나 평가표를, 상위 목표가 있으면 전략 하우스를, 한 논점의 분해면 이슈 트리를 쓴다.
   - 단계 흐름·수영 레인·순환 고리는 재료의 단계 수와 본문 칸 수(수영 레인은 칸 줄 수)를 같게 맞춘다. 맞출 사실이 없으면 다른 도식을 고른다.
   - 근거 도식은 수치 도식(수치 타일·막대·깔때기 등)이나 사례 이행·표를 먼저 고른다. 주 도식이 글 칸 도식이면 근거 도식은 글 칸 도식이 아닌 것으로 한다.
8. '본문': 칸 2~5개. 칸 이름은 내용이 드러나게 8자 안('적용 방식'·'실측 결과')이고, 칸 이름에는 콜론(:)·수치·표식(↑✓●)·번호(1.·1단계·①)를 넣지 않는다 — 변환기가 칸 이름과 줄을 이 차이로 가르고, 단계 번호는 변환기가 붙인다. 칸 아래 줄은 아래 '본문 줄 문법'으로만 쓴다. 문장을 길게 늘어놓는 줄은 쓰지 않는다.
   - 칸 줄 수는 도식 재료와 정확히 맞춘다: 전환표 = 차원 수, 평가표 = 기준 수, 표 = 머리 수 − 1, 수영 레인 = 단계 수, 사례 이행 = 2줄(전·후). 변환기는 들여쓰기가 사라진 원고에서 이 줄 수로 칸을 나눈다.
   - 주 도식이 칸을 쓰는 도식이면 본문 칸이 그 도식의 칸이 된다(전환표는 두 칸, 2×2는 네 칸을 왼쪽 위·오른쪽 위·왼쪽 아래·오른쪽 아래 순서로).
   - 근거 도식이 칸을 쓰면 그 칸 이름 앞에 `[근거]`를 붙인다.
   - 장마다 본문·근거 도식·사실 띠를 합쳐 원문 사실 9개 이상(받침은 장표에 나오지 않으므로 세지 않는다). 원문 같은 절에 쓰지 않은 사실(수치·사례·고유명사·원인)이 남았으면 더 옮긴다.
   - 제목·리드에 「N대·N가지·N개」를 쓰면 본문 칸 수도 N개여야 한다(「6대 실험」인데 칸 4개 ✗).
   - 「N단계·N가지·N대」를 쓰면 이름 N개를 모두 적는다. 갈래가 있으면 칸 이름으로 갈래를 나누고 모든 이름을 한 번씩 넣는다.
   - 대조 쌍·단계·분기 깊이를 눌러 담지 않는다. "어떻게 하는가"와 "무엇인가"는 다른 장으로 나눈다.
   - 한 사실은 덱에서 한 장에만 쓴다. 첫 장에서 뒤 장 내용을 예고로 되풀이하지 않는다. 같은 집합의 이름은 덱 전체에서 같은 말로 쓴다.
   - '본문 줄 문법' (변환기가 줄 모양을 읽어 굵은 핵심어·큰 수치·표식·막대·결론 띠로 그린다):

     | 줄 모양 | 쓰는 경우 | 예 |
     | :--- | :--- | :--- |
     | `핵심어: 설명` | 기본 줄. 핵심어 2~8자 명사, 설명 30자 안 | `조달 역량: 구매 컨설턴트 데이터로 계약 주도` |
     | `수치 설명` | 줄의 요점이 수치일 때. 수치를 맨 앞에, 25자 안 | `60% 대화 전 끝난 구매 결정` |
     | `↑ 핵심어: 설명` | 증가·개선 ↑ / 감소·악화 ↓ / 충족·채택 ✓ / 미충족·배제 ✗ / 위험 ! | `✗ 수다쟁이: 접근 쉬우나 합의 도출 능력 없음` |
     | `● 핵심어: 설명` | 수준 판정 높음 ● / 중간 ◐ / 낮음 ○ — 원문이 높고 낮음을 말할 때만. 글머리 대신 쓰지 않는다 | `● 회의론자: 까다로운 질문으로 검증` |
     | `이름 = 54%` | 전체 中 비중·달성률(0~100%) | `복잡 환경 도전자 = 54%` |
     | `결론: 문장` | 칸의 맨 끝 한 줄, 그 칸이 말하는 바(25자 안) | `결론: 변화 잠재력이 고객 선별 기준` |

   - 칸마다 줄 3~5개 + `결론:` 한 줄(2×2·카드·하우스 칸은 줄 2개로 끝내지 않는다 — 빈 면이 생긴다). 결론 줄은 칸의 맨 끝에만 두고(변환기는 결론 다음 줄을 새 칸으로 읽는다), 리드·다른 칸 결론과 같은 말을 쓰지 않는다. 전환표·표·평가표·수영 레인·사례 이행·일정표 칸에는 결론 줄을 쓰지 않는다.
   - 칸마다 수치 줄이나 표식 줄을 1개 이상 넣는다(원문에 그 칸의 수치가 없으면 표식 줄).
   - 전환표 칸 줄은 차원 순서대로 `설명`만 쓴다(핵심어 없이, 25자 안).
   - 한 장 분량 상한: 본문 줄(결론 포함) 합계 24줄, 칸당 6줄. 넘으면 장을 둘로 나누거나 근거 도식을 줄인다(넘친 장은 변환기가 근거 도식을 「(계속)」 장으로 떼어 내 흐름이 끊긴다).
9. '강조': 리드가 가리키는 수치나 칸 이름을 리드와 같은 표기로. 한 장에 하나.
10. '사실 띠': 본문에 못 넣은 조사 범위·연구·사례 사실 3~4개를 `사실 띠: <띠 이름> | <이름>: <사실> / <이름>: <사실> / <이름>: <사실>`로 쓴다. 이름 6자, 사실 25자 안, 사실 칸에는 콜론을 한 번만 쓴다.
   - 덱 본문 장의 **절반 이하**에만 쓴다(변환기는 덱당 2장만 띠로 그리고, 나머지는 빈 면이 생긴 장에서만 「참고 사실」로 꺼낸다 — 사실 띠는 중요한 장부터 쓴다). 수치·고유명사·사례가 담긴 사실만 쓰고, 어원·용어 풀이·일반론은 쓰지 않는다. 쓸 사실이 없으면 '사실 띠: 없음'.
   - 마지막 장의 추진 단계는 `사실 띠: 추진 로드맵 | 1단계: … / 2단계: … / 3단계: …`로 쓰면 단계 화살표로 그려진다.
10-1. '예비': 장표에 바로 올리지 않아도 되는 원문 재료를 장마다 8~15줄 더 쓴다. 변환기가 빈 면을 채우거나 다른 형식을 고를 때 꺼내 쓴다. 한 줄에 하나, `- 예비: <종류> | <원문 그대로>`. 종류는 수치·사례·인용(원문 사실) 또는 기준·기간·분모·위치·차원(형식 재료, `기간: 1단계 = '27 1Q`처럼). 원문에 없는 내용은 쓰지 않는다. 장 끝에 `- 예비: 확인 | 사실 N개`를 적고, 본문·예비를 합친 원문 사실이 12개 미만이면 원문에서 더 옮긴다.
11. '받침': `→ 다음 장의 물음` 한 줄. 받침은 장표에 그려지지 않으므로 남은 원문 사실은 받침이 아니라 사실 띠나 본문에 넣는다. 원문 그림·표 이름(「[그림1]」)은 옮기지 말고 그 내용을 쓴다. 마지막 장은 받침 대신, 원문이 3년을 넘었거나 단일 출처면 그 한계를 서브메시지 근거 줄에 쓴다.
12. 바꿔 쓸 말(모든 칸): '패러다임'→'방식', '시너지'→'결합 효과', '극대화'→'확대', '(단순) ~를 넘어'→'~가 아니라'. 괄호 속 영어 설명은 지우고, 전문 약어는 첫 등장에 한글 풀이를 붙인다.
13. 연도는 `'26년`·`'12년`(`'2012`·`2012년` ✗), 한자 약어 `전년比`·`外`·`中`, 증감 `↑`·`↓`.
14. 본문이 7장을 넘으면 6장까지 쓰고 마지막 줄에 `[계속]`만 쓴다. "계속"이라고 하면 다음 장부터 같은 틀로 쓴다.
15. 원문이 없으면 "기획할 원문 자료를 붙여 주십시오." 한 줄만 쓴다. 수정 요청에도 같은 틀로 다시 쓴다.

## 4. 도식 목록 — 이름과 재료 적는 법

재료는 `도식 이름 | 키: 값 / 값 | 키: 값` 한 줄로 쓴다. '칸'은 본문 칸을 쓴다는 뜻이다. 모든 도식에 `제목: …`, `단위: …`를 덧붙일 수 있다.

| 도식 이름 | 쓰는 경우 | 재료 |
| :--- | :--- | :--- |
| 전환표 | 기존과 새 방식을 차원별로 대비 | `차원: 목표 고객 / 개입 시점 / 대화 방식` + 칸 2개(기존, 새), 칸 줄 수 = 차원 수, 같은 순서 |
| 단계 흐름 | 순서가 바뀔 수 없는 단계 3~6 | 칸 = 단계(차례대로, 이름에 번호 없이 — 번호는 변환기가 붙임) |
| 인과 사슬 | 원인 → 결과 → 다음 결과 | 칸 = 고리(차례대로), 마지막이 결과 |
| 이슈 트리 | 한 논점을 가지·잎으로 분해 | `뿌리: 논점 문장` + 칸 = 가지, 칸 줄 = 잎 |
| 2×2 | 두 기준으로 대상을 넷으로 나눔 | `가로: 기준 | 세로: 기준 | 우선: 오른쪽 위` + 칸 4개 |
| 전략 하우스 | 목표 · 전략 기둥 · 기반 | `지붕: 목표 | 바닥: 기반` + 칸 = 기둥 |
| 층 띠 / 피라미드 | 위계·층위 (위가 상위) | 칸 = 층(위부터) |
| 순환 고리 | 결과가 다시 원인이 됨 | `중심: 이름`(선택) + 칸 = 단계 |
| 허브 | 한 중심에서 여럿으로 | `중심: 이름` + 칸 = 바퀴살 |
| 수영 레인 | 주체마다 단계별 활동 | `단계: 요구 인지 / 선택 평가 / 승인` + 칸 = 주체, 칸 줄 = 단계별 활동(없으면 `-`) |
| 사례 이행 | 사례마다 전 → 후 | 칸 = 사례, 칸 줄 `전 → 후` |
| 평가표 | 대안 × 기준 등급 | `기준: 비용 / 속도 / 위험` + 칸 = 대안, 칸 줄 `상 — 풀이`(기준 순서대로). 모든 칸 줄을 등급(상·중·하 또는 ●◐○)으로 시작하고 방향은 '높을수록 좋음'으로 통일 — 다르면 `범례: ● 위험 큼 · ○ 위험 작음`. 앞 두 기준이 등급으로 채워지면 변환기가 포지셔닝 맵으로도 그릴 수 있다 |
| 표 | 행 × 열 사실 | `머리: 구분 / '26 / '27` + 칸 = 행, 칸 줄 = 셀 |
| 카드 묶음 / 역할 라벨 | 관계 없는 묶음 / 배경·역량·실행 | 칸 그대로 |
| 수치 타일 | 핵심 수치 2~4개 | `값: 60% 대화 전 끝난 구매 결정 / 1,400개 조사 대상 기업` — 원문 수치(단위·`+`·`↑` 포함)를 맨 앞에 띄어 쓰고 설명은 20자 안. `(+5%)`를 붙이면 증감 표시. 「N개 중 M」은 `8곳 미국 10대 기업 중 도입`처럼 쓰면 비율 칸으로 그린다. 「1~2문장 정의 과제」처럼 수량이 아닌 말은 쓰지 않는다. **큰 숫자는 4가지를 모두 넘을 때만**: ① 리드의 주장이거나 그 직접 근거(`강조:`에 그 수치를 씀) ② 비교 대상·분모·변화·목표가 함께 있음 ③ 규모·비용·성과처럼 결정에 쓰는 수치(조사 인원·논문 수·표본 수는 ✗ → 근거 줄로) ④ 리드의 수치를 그대로 되풀이하지 않음. 근거 도식의 수치 타일은 한 장에 하나 — 못 넘는 수치는 서브메시지 근거 줄이나 본문 줄에 쓴다 |
| 막대 / 가로 막대 | 같은 지표·같은 단위의 값 3~8개(2개뿐이면 수치 타일) | `값: '25 2,527 / '26 2,660 / '27(G) 2,770 | 강조: '27(G) | 단위: 억` |
| 묶음 막대 / 누적 막대 | 대상별 여러 계열 / 합이 의미 있는 구성 | `축: '25 / '26 | 계열: 농심 1,700 1,820 / 외부 800 840 | 단위: 억` |
| 꺾은선 / 복합 | 시점별 추이 / 막대 + 비율 선 | `축: … | 계열: 매출 2,527 2,660 / 이익률(선) 8.1% 8.4%` |
| 워터폴 | 시작 → 증감 요인 → 끝 | `값: '26 실적 2,660 / 단가 -30 / 신제품 +110 / '27 목표 = | 단위: 억` |
| 깔때기 | 단계마다 줄어드는 같은 대상 수 | `값: 방문 1,200 / 문의 480 / 계약 42` |
| 묶음 막대(두 시점) | 같은 지표·같은 단위를 항목 3개 이상에서 두 시점으로 비교 | `축: '25 / '26 \| 계열: 대리점 820 760 / 온라인 210 340 / 수출 150 230 \| 단위: 억` — 축은 두 시점만. 변환기가 덤벨(값 차이)이나 슬로프(순위가 뒤바뀔 때)로 그린다 |
| 누적 막대(구성비) | 합이 100인 구성 비중의 변화 | `축: '24 / '25 / '26 \| 계열: 대리점 38 36 33 / 온라인 8 10 15 / 기타 54 54 52 \| 단위: %` — 시점마다 합이 100이면 100% 누적 막대로 그린다. 합을 맞추려고 원문에 없는 「기타」 값을 만들지 않는다 |
| 꺾은선(여러 지표) | 단위·크기가 다른 지표 2~6개의 같은 기간 추이 | `축: 1Q / 2Q / 3Q / 4Q \| 계열: 매출(억) 610 640 655 700 / 반품률(%) 1.9 1.6 1.4 1.2` — 계열 이름 뒤 괄호에 단위를 쓰면 지표마다 따로 그린 작은 그래프 묶음(스몰 멀티플)이 된다 |
| 전환표(현재·목표) | 차원별 현재 수준과 목표 수준의 격차 | 전환표 재료 그대로, 칸 이름을 「현재 수준」·「목표 수준」으로. 칸 줄은 같은 단위 수치를 맨 앞에 쓰면 격차 막대로 그린다(격차 수치는 쓰지 않는다 — 원문에 없으면 만들지 않음) |
| 단계 흐름(가치 사슬) | 주 활동의 연결과 그것을 받치는 지원 기능 | `지원: 품질 보증 / 연구개발 / 구매 조달` + 칸 = 주 활동(차례대로, 3~6개) |
| 단계 흐름(성숙도) | 수준 단계와 현재·목표 위치 | `현재: 2 \| 목표: 4` + 칸 = 수준(낮은 단계부터, 3~6개). 숫자는 칸 순서 |
| 평가표(우선순위) | 과제를 효과×실행 용이성으로 줄 세움 | `기준: 효과 / 실행 용이성` + 칸 = 과제(3~8개), 칸 줄 `상 — 풀이` 2줄. 첫 기준은 효과·영향·가치, 둘째는 용이성·난이도·비용·긴급성일 때 우선순위 매트릭스로 그린다 |
| 이슈 트리(판단) | 조건에 따라 결론이 갈리는 판단 | `뿌리: 판단할 질문` + 칸 = 첫 조건(2~4개), 칸 줄 `세부 조건 → 결과` — 줄의 절반 넘게 `→`가 있으면 의사결정 트리로 그린다 |
| 일정표 | 기간별 과제·관문 | `기간: 1Q / 2Q / 3Q / 4Q | 관문: 3Q 양산 승인` + 칸 = 과제, 칸 줄 `내용 (1Q~2Q)` |

- 같은 수치 재료로 여러 그림이 가능하면 변환기가 덱 전체를 보고 고른다. 원고는 재료(축·계열·단위·현재·목표·지원·기준)를 빠짐없이 적는 데 집중하고, 특정 그림을 꼭 원할 때만 `| 표현: 덤벨`처럼 붙인다.
- 차트(막대·묶음·누적·꺾은선·복합)는 PPT 내보내기 때 PowerPoint 기본 차트로 들어가므로 값은 숫자만 쓴다(단위는 `단위:`에). 항목 이름은 8자 안.
- 막대·꺾은선은 같은 단위끼리만. 단위가 다른 값은 수치 타일이나 표로 쓴다. 원문 수치 하나로 막대 여러 개를 만들지 않는다.
- 수치 도식(수치 타일·막대·꺾은선·워터폴·깔때기)은 본문 칸을 쓰지 않는다. 이때 본문 칸은 근거 도식이 된다.

## 7. 내기 전 점검 — 실행 덱에서 자주 어긋난 7가지

답변을 내기 전에 아래를 하나씩 확인하고, 어긋난 장은 고쳐서 낸다.

1. 리드가 40자를 넘지 않는가(넘으면 장표에서 두 줄로 꺾인다).
2. 주 도식이 칸을 쓰는데 그 칸에 `[근거]`를 붙이지 않았는가. `[근거]`는 근거 도식 칸에만 붙인다.
3. 근거 표의 행을 `[근거] 행 이름 / 셀 / 셀`처럼 한 줄에 몰아 쓰지 않았는가. 행마다 `[근거] 행 이름` 칸을 만들고 그 아래 줄로 셀을 쓴다.
4. 근거 도식을 `표`로 적었다면 `[근거]` 칸이 실제로 있는가. 없으면 근거 도식을 `없음`으로 둔다.
5. 같은 수치가 리드·본문 줄·도식에 세 번 나오지 않는가. 리드에 쓴 수치는 도식이나 본문 한 곳에서만 받친다.
6. 워터폴은 시작 → 증감 → 끝일 때만 쓴다. 부분의 합이 전체인 구성(60 + 40 = 100)은 누적 막대나 수치 타일로 쓴다.
7. 본문 칸 줄이 9개 미만인 장은 원문에서 사실을 더 옮기거나 옆 장과 합친다(예비층 8~15줄 포함).
