### 본문 2 : Ⅰ- 2. AI가 전략적 사고를 확장하는 3가지 방식
- 물음: AI는 이 병목을 어떻게 넓히는가
- 연결: 대응 — 앞 장 병목의 해법
- 비중: 핵심
- 리드: ✓ AI는 탐색·표현·종합의 3대 인지 과제를 혁신하여 수천 개의 대안과 고해상도 모델을 제공
- 서브메시지:
  - 근거: M&A, 마이뱅크, P&G 등 글로벌 기업 도입 사례 분석
- 주 도식: 이슈 트리 | 뿌리: 전략적 의사결정 혁신
- 근거 도식: 표 | 머리: 구분 / 기존 인간 방식 / AI 기반 방식
- 본문:
  - 대안 탐색
    - 숏리스트 확장: 수천 개의 대안 생성 및 필터링 비용 급감
    - M&A 사례: 4,000만 개 데이터베이스로 500개 인수 대상 발굴
    - 결론: 탐색은 AI가 담당하고 선택은 인간이 수행
  - 환경 표현
    - 동적 고해상도 모델: 정적 프레임워크를 실시간 데이터 모델로 대체

    - 결론: 저해상도 모델을 고해상도로 교체하여 신규 기회 포착
  - 의견 종합
    - 합성 심의: 위계와 집단사고를 배제한 구조화된 이의 제기
    - 워게임 시뮬레이션: 에이전트를 통한 경쟁사·규제당국 반응 테스트
    - 결론: 객관적인 비평과 압박 테스트로 결정 품질 향상
  - [근거] 대안 탐색

### 본문 3 : Ⅱ- 1. 모두가 AI를 가진 세상에서 우위를 구축하는 법
- 물음: 모두가 AI를 쓰면 우위는 어디서 오는가
- 연결: 전환 — 도구에서 경쟁우위로
- 비중: 핵심
- 리드: ✓ 독점적 데이터, 고유 프로세스, 지속적인 프런티어 이동을 통해 모방 불가능한 해자를 구축
- 서브메시지:
  - 근거: 모건스탠리, 존디어, 듀오링고 사례 분석
- 주 도식: 카드 묶음
- 근거 도식: 수치 타일 | 값: 50~77% 존디어 제초제 절감
- 본문:
  - 독점 데이터로 파인튜닝
    - 사내 리서치 및 거래 패턴 결합: 경쟁사가 복제할 수 없는 자산 구축
    - 모건스탠리 사례: 1만 6천 명 재무설계사, 리서치 접근성 및 검색 효율 80% 달성
    - 결론: 독점 데이터가 강력한 해자로 작용
  - 고유 프로세스에 AI 심기
    - 독점적 워크플로 통합: 하드웨어 및 네트워크와 결합된 차별화 역량
    - 존디어 사례: 정밀농업 장비로 분사 결정 자동화 및 수익원 다변화
    - 결론: 프로세스 내재화로 고객 종속 강화
  - 새로운 프런티어로의 신속한 이동
    - 운영 효과성 넘어선 진화: 독자적 학습 모델로 지속적 우위 확보
    - 듀오링고 사례: 5억 명 사용자 행동 데이터 학습 모델(버드브레인) 운영
    - 결론: 지속적인 프런티어 도달 능력이 핵심 우위
- 사실 띠: 기업별 해자 | 모건스탠리: 사내 10만 건 리서치 문서 연동 / 스트라이프: 연 1조 4천억 달러 결제 데이터 학습 / 듀오링고: 일 12억 개 문제 풀이 데이터
- 강조: 해자

### 본문 4 : Ⅱ- 2. AI 시대를 위한 리더의 플레이북
- 물음: 리더는 무엇을 바꿔야 하는가
- 연결: 대응 — 앞 장 우위를 실행으로
- 비중: 보통
- 리드: ✓ 대안 확장, 동적 모델 전환, 이의 제기 제도화 및 하이브리드 전략가 육성이 관건
- 서브메시지:
  - 근거: HBR 경영진 리디자인 플레이북 제안
- 주 도식: 단계 흐름
- 근거 도식: 표 | 머리: 구분 / 기존 방식 / AI 기반 플레이북
- 본문:
  - 의사결정 프로세스 재설계
    - 롱리스트 확보: 중대한 결정 전 AI를 통한 폭넓은 대안 탐색 선행
    - 동적 모델 업그레이드: 정적 스냅샷을 실시간 갱신 모델로 교체
    - 결론: 의사결정의 기초 토양을 전면 개편
  - 검증 및 인재상 변화
    - 이의 제기 제도화: 창작자-비평가 워크플로로 약점 사전 식별
    - 하이브리드 전략가 육성: 데이터를 넘어 프로세스를 설계하는 인재 확보
    - 결론: 전략가의 역할을 분석가에서 시스템 설계자로 전환
  - [근거] 대안 탐색
    - 숏리스트 중심 토론
    - AI 활용 롱리스트 사전 검토
  - [근거] 모델링
    - 분기별 스프레드시트
    - 실시간 갱신 동적 모델
  - [근거] 검증 방식
    - 위계 중심 회의
    - 창작자-비평가-경쟁자 워크플로
